eIRB: User Guide: Comparison v1 July 28, 2022 eIRB DOCUMENT COMPARISON FEATURE

OVERVIEW The NASA eIRB system is configured to promote automatic versioning of documents and comparison of historic versions. This functionality eliminates the need for the PI to upload of tracked-changes versions of documents, simplifies review, creates an audit trail, and reduces administrative burden. FACILITATING VERSIONING/ DOC UMENT -COMPARE FEATURE When updating documents either during the review process or as part of an amendment (i.e., modification (Mod) or modification and continuing review (ModCR)) select “update.” Note: The versioning feature works only when documents are updated (i.e., not added as separate documents) within the system.

Then select the new/updated Word file to replace the original.

You may rename or specify a version number (if no version number is specified the system will automatically note the version (0.x) following the document name).

This Quick Guide covers • Uploading documents to facilitate eIRB versioning and tracked changes comparison • Viewing document history • Comparing versions of Microsoft Word documents* * documents for comparison feature must be MS Word format (i.e., not pdf)

eIRB: User Guide: Comparison v1 July 28, 2022 VIEW CHANGES TO SMARTFORM During review, you can view the overall changes to the submission Smartform. From the workspace page, select “View Study.” On the following page, select “compare” on the left-side-menu.

Areas with changes marked with pencil icon. The right-side of the workspace will highlight Smartform revisions. Audit information including the old value, user who edited, and time of edit are also shown.

Select version timepoint for comparison

OVERALL VERSION HISTORY FROM STUDY WORSPACE

It is possible to view and compare documents across the entire history of a study. Begin by accessing the overall study workspace (i.e., Study000XXX – not a specific Mod or ModCR).
